# git-practice

Учебный проект для освоения Git, GitHub и pull request'ов.

## Цель

Практика работы с репозиторием: инициализация, коммиты, просмотр истории,
связывание с удалённым репозиторием и клонирование.

## Использование

```bash
python main.py
python main.py GitHub
```

Пример вывода: `Привет, GitHub!`
